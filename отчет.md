### 3. Агент корректно вызывает нужный tool ###

- Запрос: «Кто такая Хозяйка Медной горы? Используй bazhov-reference».
- Ожидаемый tool: `bazhov_resolve` (поиск сущности по названию/алиасу).
- Фактическое подтверждение:
```
2026-09-25 23:38:58,823 INFO [bazhov-mcp] bazhov_resolve <- {"query": "хозяйка медной горы", "entity_type": null}
2026-09-25 23:38:58,824 INFO [bazhov-mcp] bazhov_resolve -> 2 results, 0 candidates (0.3 ms)
2026-09-25 23:38:58,824 DEBUG [bazhov-mcp] bazhov_resolve full result: {"results": [{"id": "story:mednoy-gory-khozyayka", "title": "Медной горы Хозяйка", "type": "story", "summary": "Медной горы Хозяйка (1936)"}, {"id": "char:khozyayka-mednoy-gory", "title": "Хозяйка Медной горы", "type": "character", "summary": "Хозяйка Медной горы"}], "candidates": []}
```
- Ответ в консоли пользователя:
```
+ Thought: 3.5s
⚙bazhov-reference_bazhov_resolve [query=хозяйка медной горы]
+ Thought: 3.6s
⚙bazhov-reference_bazhov_get [id=char:khozyayka-mednoy-gory]
+ Thought: 5.0s
Хозяйка Медной горы (Малахитница, горная девица) — в сказах Бажова покровительница горняков и хранительница секретов мастерства: сизо-чёрная коса, платье из шёлкового малахита. Испытывает людей, карает жадных (приказчик Северьян) и помогает настоящим мастерам; появляется в сказах «Медной горы Хозяйка» (1936), «Каменный цветок», «Малахитовая шкатулка», «Горный мастер» и др.
```

- Цепочка, как и ожидалось: `bazhov_resolve` → `bazhov_get` по id из результатов поиска.
- Где хранится подтверждение: врезки логов и транскрипт агентской сессии приведены прямо в этом отчёте
  (два блока выше); отдельного каталога с артефактами в репозитории нет.
- Воспроизведение: `BAZHOV_LOG_LEVEL=DEBUG .venv/bin/python scripts/smoke_client.py` (те же строки
  лога появятся в stderr) и повтор запроса «Кто такая Хозяйка Медной горы? Используй bazhov-reference»
  в MCP-клиенте, подключённом через `opencode.json`.
